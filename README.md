# Webしりとりアプリ
## デプロイ先URL
https://shiritoriapp.hisiki-haruto.deno.net/
## 実装した機能
### 必須機能
- 直前の単語を、表示できるようにする
- 任意の単語を、入力できるようにする
- 直前の単語の末尾と、入力した単語の先頭を比較して、同じ場合だけ単語を更新する。違う場合は、エラーを表示する
- 末尾が「ん」で終わる単語が入力されたら、ゲームを終了する
- 過去に使用した単語が入力されたら、ゲームを終了する
- ゲーム中や終了後に、最初からやり直せるリセット機能をつける
### 追加した機能
- 辞書検索機能
  - SKK-JISYO.L.unannotatedを利用し、存在する単語のみ入力できるようにした。
- 使用する文字の自由度と統一
  - 漢字やカタカナでの入力に対応した。
  - 小文字（ゃ・ゅ・ょ・っ など）を通常の文字として扱えるようにした。
  - 濁点・半濁点を同じ音として判定できるようにした。（例：か ⇔ が、は ⇔ ば ⇔ ぱ）
  - 長音「ー」を考慮して判定できるようにした。（長音の直前の音が判定される）
- スコア・スコア履歴機能
  - 送信するまでの時間に応じて獲得スコアが変動するようにした。
  - 正しい単語であれば加点、空欄入力や間違った単語の入力では減点されるようにした。
  - リセット（終了）時にスコアを保存し、過去のスコアを確認するようにした。
- 使用単語履歴表示機能
  - 使用した単をが直前５単語分表示し、プレイヤーに若干のヒントを与えるようにした。
- 遊び方説明の追加
  - ルールがわかりやすいようにルール説明を追加した。
